Craft Hub

Os apps Craft rodando nativos no Android. Instale o hub e escolha quais apps baixar.

Baixar o Craft Hub (APK)

Android 8 ou mais novo, processador ARM 64 bits.

Como instalar

  1. Abra esta página no celular e toque em Baixar o Craft Hub.
  2. Abra o arquivo baixado. Se o Android pedir, permita que o navegador instale apps.
  3. No Craft Hub, toque em Baixar no app que quiser. Na primeira vez, permita que o hub instale apps.

Apps

Versões para Android dos apps do ArtCraft (storytold), de código aberto (Apache-2.0), compiladas a partir do código original. Código desta adaptação: Patrick-Dalton/craft-mobile.
